YOUR DOCX WEBSITE

PUBLISH ON NETLIFY
1. Open Netlify Drop in your browser.
2. Drag this ZIP directly into the deploy area. Do not extract it first.
3. Netlify will publish the site and provide a shareable address.
4. Open the published site once while online so its offline files can be saved.

UPDATE THE WEBSITE
Edit the original DOCX, rebuild the website, and deploy the replacement ZIP to the same Netlify site.

You can also extract this ZIP and upload the files to any static web host. A custom domain is optional.

Install icons are in /icons. Search is built into the page and needs no service. Reading progress is stored only in each reader’s browser. The generated site includes installation guidance. The manifest and service worker make the hosted website installable and available offline after its first successful visit.

The generated site includes required DOCX Website attribution. Your original document content remains yours.
